# Встроенный LUT DJI Osmo Action 5 Pro

`dji_osmo_action_5_pro_dlog_m_to_rec709_v1.cube` — файл, предоставленный пользователем
как `DJI OSMO Action 5 Pro D-Log M to Rec.709 V1 (2).cube`. Содержимое скопировано
без изменений: таблица 33×33×33, 35 937 RGB-записей.

SHA-256: `b18162854ab47702068410c33afa98a8cb6eef159fc5a04ce0e65fad0fd8947e`.

В режиме «D-Log M + LUT» программа использует его по умолчанию. Отдельное
скачивание, установка или выбор файла не требуются. Для работы перенесите всю
папку программы вместе с `assets`; путь определяется относительно исходников,
а не текущей рабочей папки или буквы диска.

Этот LUT предназначен для материала Action 5 Pro, снятого в D-Log M. Для обычного
цветового профиля оставьте «Без коррекции» или выберите ручную настройку.
Профиль записи автоматически не определяется. Свой внешний `.cube` можно
выбрать кнопкой «ДРУГОЙ LUT», а вернуться к встроенному — «ВСТРОЕННЫЙ DJI».
