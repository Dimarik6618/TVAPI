# Медленный анализ: Windows и NVIDIA RTX 5050 Laptop

Для записи 16 ГБ, предположительно около 20 минут, семь часов обработки требуют
проверки этапа и фактического устройства вычисления. По названию видеокарты
нельзя установить, использует ли её программа. Точного ускорения на этом компьютере
пока не измеряли.

При обновлении закройте Moto Shorts и сначала сохраните копию старой папки.
Скопируйте файлы новой версии в прежнюю папку программы, сохранив `.venv`,
`learning_data`, проекты и исходные видео. В архиве нет этих личных данных,
поэтому он не требует их удаления или сброса обучения.

## 1. Проверить используемую сборку PyTorch

Закройте программу и запустите **`Check_NVIDIA.bat`** из той же папки.
Он проверяет `.venv` программы, показывает версию PyTorch, CUDA и GPU,
а затем выполняет небольшое настоящее вычисление на CUDA.
Весов моделей и видео эта проверка не скачивает.

Признаки готового GPU-режима:

```text
CUDA in PyTorch: 12.8
CUDA available: True
Inference device: cuda:0
CUDA computation: PASS
```

Другая совместимая версия CUDA также может работать. `CUDA available: True`
без успешного вычисления недостаточно. При ошибке ядра или нехватке памяти
проверка показывает причину. Встроенная команда **ПРОЕКТ → ПРОВЕРИТЬ ОБОРУДОВАНИЕ**
также дополнена версиями PyTorch/CUDA и архитектурой GPU.

## 2. Если установлена CPU-сборка или несовместимая CUDA-сборка

Для RTX 50-й серии добавлен **`Install_NVIDIA_RTX50.bat`**. Запускайте его при
закрытой программе, после установки нужных `Установить_*.bat`.
Он устанавливает совместимую пару `torch 2.9.1` и `torchvision 0.24.1` с CUDA 12.8
из официального индекса `https://download.pytorch.org/whl/cu128`.
Наличие Windows-колёс и требование torchvision к этой версии torch проверены
по метаданным официального индекса. Сам BAT в Windows здесь не запускался.

Загрузка пакетов может быть большой. Нужен установленный драйвер NVIDIA,
совместимый с этой CUDA-сборкой. В конце скрипт проверяет вычисление на GPU;
если оно не прошло, скрипт сообщает об ошибке, а не об успешной настройке.
Затем перезапустите Moto Shorts, чтобы модели загрузились в новом окружении.

Этот установщик относится к моделям на PyTorch. Распознавание речи в текущей
реализации faster-whisper по-прежнему использует CPU/int8.

## 3. Отключить необязательное получение признаков

В **НАЙТИ МОМЕНТЫ → параметры анализа** появилась галочка
**«Признаки для обучения без оригиналов (дольше)»**. По умолчанию она включена,
сохраняя прежний процесс работы. Настройка сохраняется в проекте и учитывается
при продолжении очереди и проверке изменённых границ.

При выключении таймкоды, оценки и решения остаются в памяти событий, но
новые визуальные признаки специально для памяти не вычисляются. Совместимые
ранее сохранённые признаки используются повторно. Если признаки уже создал
включённый визуальный классификатор, они также сохраняются.

Для новых событий без признаков обучение без оригиналов недоступно. Автоматическая
очистка Drive по-прежнему блокируется, пока нужные признаки отсутствуют;
временный MP4 остаётся на диске. Эта галочка не выключает выбранные объекты,
сюжет, речь или отдельно включённую обученную модель.

Для пробного поиска только по движению/звуковой активности выключите дополнительные
виды ИИ, эту галочку и использование обученного классификатора в окне обучения.
Такой поиск может пропускать спокойные визуальные и разговорные события.
Используйте короткую запись, чтобы сначала проверить скорость и качество.

## 4. Повторный анализ и отчёт

Готовая совместимая запись признаков для точных границ теперь читается напрямую
из SQLite. Повторно загружать модель и проходить составляющие её окна не требуется.
Повреждённые и несовместимые признаки пересчитываются в полном режиме.

После обработки в папке вывода появляется **`moto_performance.json`**.
Сохраняются время этапов каждого файла и итоговый статус, включая ошибку/остановку:

- `source_prepare`: подготовка исходника, включая загрузку и проверку Drive;
- `scan`: декодирование и базовые сигналы либо чтение их из кэша;
- `speech`: распознавание речи;
- `model_initialization`: подготовка дополнительного анализатора;
- `trained_discovery`, `trained_scoring`: обученный визуальный отбор;
- `objects_sound_meaning`: дополнительные модели;
- `event_memory`: память событий и необходимые визуальные признаки.

Отсутствующий этап не выполнялся. Ленивая загрузка весов входит во время того этапа,
который первым обратился к модели. Сумма этапов может быть меньше общего времени:
оставшееся время включает выбор кандидатов, проект, очистку и другие операции.
Значения даны в секундах, имена файлов записаны без полного пути.

Если долго занимает `source_prepare`, сначала нужно исследовать загрузку и диск.
Если `event_memory` — полезны готовые признаки, отключение их сбора для пробного
поиска или рабочий GPU. Если `scan` — проверьте наличие подходящего одноимённого
`.LRF` рядом с локальным MP4 и включённую опцию прокси. Если `speech`, время
зависит от распознавания на CPU.
