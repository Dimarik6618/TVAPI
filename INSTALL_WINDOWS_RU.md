# Установка Moto Shorts на Windows из GitHub

[Скачать ZIP программы со встроенным LUT](https://github.com/Dimarik6618/TVAPI/archive/refs/heads/codex/windows-with-lut.zip)

1. Если Python ещё не установлен, установите **Python 3.12, 64-bit**
   с [python.org](https://www.python.org/downloads/windows/), включив **Add Python to PATH**.
2. Скачайте ZIP по ссылке выше и распакуйте **всю папку** в удобное место.
3. Откройте распакованную папку, где лежит `moto_shorts.py`, и дважды нажмите
   **`Запустить.bat`**. При первом запуске он создаст `.venv` и установит
   базовые зависимости, затем откроет программу.
4. Для снятых в D-Log M записей в окне экспорта выберите **«D-Log M + LUT»**.
   LUT Action 5 Pro уже входит в `assets`; отдельно скачивать его не нужно.
   Если в проекте сохранился путь к прежнему файлу, нажмите **«ВСТРОЕННЫЙ DJI»**.

Для Normal и других цветовых профилей оставьте подходящий режим обработки;
встроенный LUT предназначен для D-Log M. Автоматическое определение профиля не добавлено.

Для Google Drive, речи и нейросетевых дополнений сохранены отдельные
`Установить_*.bat`. Они устанавливаются по необходимости; для самого LUT
дополнительные Python-пакеты не нужны.

Для NVIDIA RTX 5050 Laptop и других RTX 50 см. [проверку GPU и ускорение](PERFORMANCE_WINDOWS_RU.md).
Сначала установите нужные дополнения, затем при необходимости используйте
`Install_NVIDIA_RTX50.bat` и перезапустите программу.

Если программа уже установлена, сначала сохраните копию прежней папки. Новую
версию можно проверить отдельно. Для переноса своей истории и обучения сохраните
`learning_data`, проекты и оригиналы видео. Рабочее окружение `.venv` при новой
установке создаётся автоматически.

## Если установлен Git for Windows

Откройте PowerShell в папке, куда хотите установить программу:

```powershell
git clone --branch codex/windows-with-lut --single-branch https://github.com/Dimarik6618/TVAPI.git MotoShorts
if ($LASTEXITCODE -eq 0) {
    Set-Location MotoShorts
    & '.\Запустить.bat'
}
```

Клонирование выполняется в новую папку `MotoShorts`; существующая папка не
перезаписывается. Архив ZIP позволяет установить программу без Git.
